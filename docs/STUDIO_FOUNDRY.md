# Studio Foundry — 12 original editable Rive art directions

**Status: proof-of-execution, not independently rated aesthetic excellence.** The studio is deliberately a creative *scene* library, not a synonym-heavy motion recipe corpus. Branch: `feat/motion-showcase-multigenre` from `feat/motion-recipe-atlas`.

| quantum | Silicon processor | chip layers + 56 side contacts + pulse traces |

All are original vector artwork, editable shape/text tracks, 720×460 artboards. Each scene has multiple animation tracks — hero depth arrival, staggered headline and copy, ambient shift and independently animated accent — and deliberately no third-party art downloads. The **same base staging grammar is still shared**: this is a starting testbed for stronger bespoke scene-specific timing, not a claim that all 12 have unique choreography.

## Real runtime artifacts

The CI workflow uses GitHub Actions matrix with 12 real scene jobs, up to 6 concurrently. Each builds a native RIVE through the repo's `createRiv`, independently checks source structure and actual compiled animation, uses the pinned official Rive canvas runtime in Chromium to inspect the artboard and render **46 PNG frames at 10fps**, then uses ffmpeg for an actual GIF. Each job uploads `<scene>.riv`, `<scene>.gif`, `<scene>-poster.png` and a proof manifest.

All source artwork is generated by this repository. Text uses its bundled Inter font, whose redistributability must be considered separately from the vector work; this note does not override any actual font license.

Run locally after build:

    npm ci
    npm run build
    node test/studioFoundry.mjs
    node scripts/studio-foundry-scenes.mjs vesper test/tmp/studio-foundry/vesper.riv
    RIVE_MCP_CHROME=/absolute/playwright/chromium node scripts/studio-foundry-render.mjs vesper test/tmp/studio-foundry/vesper

## Limits and required next quality gate

- This is a **proof of 12 distinct, inspectable, editable scene concepts**. Not 12 user-validated exceptional works.
- The 60 role-based motion recipes are independent from this. Adding a recipe number does not automatically create new geometry or composition.
- The visual effects are primarily vector gradients, stroke/fill/transforms; no shader-rendered materials or real 3D claimed.
- Visual review must inspect actual image frames and fix text overflow, cropping, contrast, generic layouts, poor movement and similarity.
- To claim "astonishing," run unseen prompt creation and blind head-to-head evaluation against professional references and different generation routes, with the same font/asset/model/budget. This has **not** been done.
- Scene diversity and editability are measured, **human aesthetic preference is NOT_EVALUATED** until a real panel reviews the work.

Acceptance requires all 12 CI jobs passing, 12 distinct authored shape graphs, and links to real GIF/PNG/native Rive evidence. Any failure must be reported as failure, not waved through.
